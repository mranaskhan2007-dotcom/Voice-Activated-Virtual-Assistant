# Virtual Assistant 

A Python-based voice assistant that performs tasks through voice commands and provides AI-powered responses using Google Gemini.

## Features
- Voice activation using "Jarvis"
- Open websites like Google, YouTube, Facebook and GitHub
- Play music through voice commands
- Get the latest news headlines
- AI-powered answers using Gemini

## Technologies Used
- Python
- SpeechRecognition
- pyttsx3
- Google Gemini API
- NewsAPI

## Setup

1. Clone this repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Add your API keys to a `.env` file (`GEMINI_API_KEY` and `NEWS_API_KEY`).
4. Run the project:

```bash
python main.py
```
